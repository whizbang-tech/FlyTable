# Contributing

Swift 6 language mode, macOS 15 / iOS 18 / visionOS 2 floor. Build with `swift build`, test with
`swift test`, look with `swift run FlyTableGallery`. Core changes need tests; renderer changes need
a look in the gallery and, when they affect speed, a before/after measurement with the Animation
Hitches instrument. Keep synthetic data synthetic. Open a pull request against `main`.
